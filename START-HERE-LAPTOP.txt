CONTINUE ANALYSIS / DEVELOPMENT
The complete source is in flakefinder/, scripts/, tests/, configs/, generated/,
and research/. Use Python 3.11 or later and a new virtual environment on the
laptop. From this project directory, run:
  python -m venv .venv
  [activate that virtual environment using your operating system]
  python -m pip install -e .
The original requirements-lock.txt records the Windows acquisition environment
and includes Windows-only packages. It is preserved as provenance; do not
blindly install that file on macOS. requirements-analysis-lock.txt omits the
Windows hardware bridge packages for offline analysis.

The preserved baseline analysis is flakefinder/staged_features.py. Its command
entry point is scripts/analyze_staged_features.py. New pixel/terrace work is in
flakefinder/terrace_analysis.py and scripts/analyze_terraces.py. Work on a new copy/version
of analysis outputs when changing the algorithm. Keep original source masks,

SCIENTIFIC STATUS
All 1,386 planned raster fields were acquired. This is not all 15 chips.
chip002's northern tip is not yet verified as fully covered; chip001 has a
tilt-related full-field focus limitation. Details: overnight-outcome.txt/json.
The contrast plot uses measured per-object local RGB contrast, not image pixels:
  (local substrate - feature) / local substrate
Positive values are darker; negative values are brighter. Unmeasured objects
are explicitly counted. Overlap can produce multiple observations of one object.
Proposals are optical features; there are no validated monolayers in this batch.
Known user-rejected bare-substrate examples and later debris matches must not
be reused as positive thin-flake training labels.
